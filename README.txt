КОШЕЛЁК — как установить на телефон
====================================

Приложению нужен адрес в интернете (https). Проще всего — бесплатный GitHub Pages.

1. Зайдите на github.com и зарегистрируйтесь (бесплатно).
2. Нажмите «+» → New repository. Название: koshelek. Отметьте Public. Create repository.
3. На странице репозитория: «uploading an existing file» → перетащите ВСЕ файлы из этого архива
   (index.html, manifest.json, sw.js, иконки .png) → Commit changes.
4. Settings → Pages → Branch: main, папка / (root) → Save.
5. Через 1–2 минуты приложение будет по адресу:
   https://ВАШ-ЛОГИН.github.io/koshelek/

Установка на телефон
--------------------
Samsung (Chrome или Samsung Internet): откройте адрес → кнопка «Установить на телефон»
внизу приложения, либо меню ⋮ → «Добавить на главный экран» / «Установить приложение».

Huawei (браузер Huawei / Petal или Chrome): откройте адрес → меню → «Добавить на рабочий экран».

iPhone (Safari): «Поделиться» → «На экран Домой».

Важно
-----
• Записи хранятся только на том телефоне, где вы их вводите. На двух телефонах будут разные данные.
• Регулярно нажимайте «Сохранить резервную копию» — файл попадёт в «Загрузки».
  Чтобы перенести данные на другой телефон, передайте файл и нажмите «Восстановить из копии».
• После первого открытия приложение работает без интернета.

Голосовой ввод
--------------
Кнопка с микрофоном между «Расход» и «Доход». Скажите, например:
  «продукты 8500, такси 2000 вчера»
  «получил зарплату 350 тысяч»
Приложение само найдёт сумму, категорию и дату; перед сохранением их можно поправить.
На Samsung (Chrome) распознавание работает прямо по кнопке.
На Huawei без сервисов Google кнопка может не сработать — тогда нажмите на поле ввода
и диктуйте через микрофон на клавиатуре, результат разберётся так же.
